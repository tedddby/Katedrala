The engine runs today as a TypeScript library, from a clone of the repository. npm packages are planned for v1.

Deterministic
Available today
The same files, configuration and Katedrala version produce the same document, byte for byte. Two analyses of CodeVerse came out identical.
Versioned schemas
Available today
The document format is specified as JSON Schema, generated from its TypeScript types and versioned in the repository. Today, analyzeStructure returns the document's structural sections.
Local
Available today
Analysis runs on your machine. No network calls, no language model, nothing uploaded.
